# ニコリタイピング

**ニコリタイピング**は、小学生やタイピング初心者が、楽しみながらキーボード入力を練習できるブラウザ型タイピング学習サイトです。

海をテーマにした親しみやすいデザインと、段階的に進められる学習モードを通して、キーの位置・ローマ字入力・正確なタイピングの習得を支援します。

## リポジトリ

https://github.com/nikorihito/nikori-typing

## 公開ページ

https://nikorihito.github.io/nikori-typing/

※GitHub Pagesの設定完了後に公開されます。

## 主な機能

- 段階的に学べるレベルアップモード
- 制限時間内でスコアを競うノーマルモード
- 継続して記録に挑戦できるエンドレスモード
- 日本語・英語の問題切り替え
- 漢字のふりがな表示切り替え
- キーボードガイド表示
- 複数のローマ字入力方式に対応
- スコア・正確率・打鍵数・コンボの表示
- ブラウザ内への進捗保存

## 対象

- タイピングを初めて学ぶ小学生
- ローマ字入力を練習したい方
- プログラミング学習に必要な入力操作を身につけたい方
- レッスン前のウォームアップや自主練習で利用したい方

## ローカルでの実行方法

このリポジトリをダウンロード、またはクローンします。

```bash
git clone https://github.com/nikorihito/nikori-typing.git
cd nikori-typing
```

簡単に確認する場合は、`index.html`をブラウザで開いてください。

ローカルサーバーを使用する場合は、次のコマンドを実行します。

```bash
python -m http.server 8000
```

起動後、ブラウザで以下を開きます。

```text
http://localhost:8000/
```

## データ保存について

ユーザー情報や進捗データは、現在ブラウザのローカルストレージに保存されます。

そのため、以下の場合はデータを引き継げないことがあります。

- 別の端末やブラウザを使用した場合
- ブラウザの保存データを削除した場合
- シークレットモードを使用した場合

氏名や個人情報ではなく、教室用のニックネームや管理番号の利用を推奨します。
